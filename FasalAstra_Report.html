⚠️ Dataset Engineering Note: 16 source datasets were downloaded containing ~48,000 images total. However, ~32,000 of these were classification-only datasets with no bounding box annotations — useless for YOLO detection training. After filtering via 02_rebuild_merge.py, only the 15,995 images with valid YOLO bbox labels were retained. This 100% label coverage is what makes training metrics meaningful.

🔄 Class Remapping Strategy

All 16 source datasets used different class ID schemes (some 2-class, some 5-class, some 8-class). The 02_rebuild_merge.py script enforces a single canonical mapping:

# 02_rebuild_merge.py — canonical class remap Source: "weed" → class 0 (weed) Source: "crop" / "plant" → class 1 (crop) Source: "soil" / "bg" → class 2 (soil) # Split: 90% train / 10% val, unique filenames enforced # Result: 14,395 train + 1,600 val = 15,995 total
