Verdict: YOLO11n is the Optimal Choice for FasalAstra

After evaluating 8 architectures, YOLO11n delivers the best balance of accuracy (71.4% mAP50), edge speed (18-22 FPS on RPi4 via NCNN), and memory footprint (2.6M params / 5.4 MB) for real-time weed detection on resource-constrained hardware. Larger models like Grounding DINO achieve higher accuracy but are physically impossible to run on a Raspberry Pi 4 or ESP32-S3. Lighter models like MobileNetV3-SSD are faster but sacrifice critical detection accuracy needed for precise weed-vs-crop discrimination in Indian farmland conditions.

🟢 Why YOLO11n Wins

Latest C2PSA attention mechanism, improved feature pyramid, and 15% fewer FLOPs than YOLOv8n at higher mAP. Native ONNX/NCNN export for ARM Cortex-A72.

RPi4 target: 18-22 FPS @ 320px ✓

🟡 Why Not YOLOv9

PGI + GELAN architecture is more accurate but 3× heavier (7.7M params). Drops below real-time (8-12 FPS) on RPi4 — unacceptable for live spraying.

RPi4 reality: 8-12 FPS — too slow ✗

🔴 Why Not Grounding DINO

Transformer-based model requires 662 MB VRAM minimum. RPi4 has 1-4 GB shared RAM. Inference takes 2-5 seconds per frame — impractical for real-time agriculture.

RPi4 reality: <1 FPS — impossible ✗

🔵 Why Not MobileNet

Extremely fast (28 FPS) but only ~48% mAP — too many false positives would cause the solenoid to spray herbicide on crops, defeating the purpose.

Accuracy gap: 23% lower mAP ✗
