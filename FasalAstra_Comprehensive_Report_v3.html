1. Project Overview

1.1 Problem Statement

Indian farmers lose ₹50,000–₹1,00,000 per acre annually due to weed infestation. Current solutions — manual labor or blanket herbicide spraying — are either heavily labor-intensive or environmentally destructive. Blanket spraying wastes 70-80% of herbicide on bare soil and damages surrounding crops through chemical drift.

1.2 Proposed Solution

FasalAstra is an AI-powered wand-style device that a farmer walks through their field with. It operates entirely offline:

  1. Sees weeds in real-time using an OV5647 camera and a localized YOLO26 AI model.
  2. Calculates the exact moment the weed will pass under the spray nozzle using kinematic physics.
  3. Fires a precise 50ms herbicide burst — targeting strictly the weed, avoiding crops entirely.

1.3 Key Innovations

InnovationWhat It DoesWhy It Matters
Kinematic Prediction Calculates spray timing using Ti = D/V − 40ms Hits moving targets with ±5mm precision.
Anti-Double-Trigger Locks weed positions for 2 seconds internally. 5-10× reduction in herbicide waste per weed.
Crop Exclusion Zone Aborts spray if weed overlaps crop by >15%. Prevents collateral crop damage entirely.
Edge Deployment Runs completely on Raspberry Pi 4 CPU. No external internet or cloud required for farms.
Homography Mapping Converts camera pixels directly to physical distance. Eliminates the cost of expensive ultrasonic LiDARs.

2.3 Real-Time Internal Decision Flow

In the field, when the camera captures a frame (~33ms interval at 30 FPS):

  1. YOLO Inference: Evaluates bounding boxes for 'Crop' and 'Weed'.
  2. Anti-Double-Trigger: Checks if this exact weed centroid was tracked in the last 2000ms. If YES, skip.
  3. Exclusion Zone: Checks if Weed Box overlaps Crop Box by > 15%. If YES, totally abort to protect crop.
  4. Homography & Physics: Converts Pixel Y-Coordinate to physical Meters. Calculates Time_to_Impact.
  5. Solenoid Fire: Delays the internal thread by Time_to_Impact, then pulses the GPIO HIGH for exactly 50ms.

3.3 Real-World Data Augmentation

To prepare the AI for the harsh physical realities of Indian farms, mathematical noise was blasted into the dataset during training:

  • HSV Shift (Saturation/Value): Simulates poor camera quality when transitioning from bright sunlight to canopy shadows.
  • Cutout Erasing (40% coverage): Mentally teaches the AI to track weeds even if droplets of mud stick to the OV5647 camera lens.
  • Translation / Scale: Simulates motion blur from a farmer walking fast.

5. Kinematic Physics — The Core Innovation

5.1 The Displacement Problem

A farmer walks with the wand at approx 1.0 meters per second. When the camera detects a weed 40cm ahead, if the solenoid fires instantly, the herbicide hits the ground 40cm behind the weed because the farmer is physically moving. We must predict the future.

5.2 The FasalAstra Physics Formula

Ti = (D / V) − Latency_total

• Ti: Target firing delay (milliseconds)
• D: Physical distance to weed (meters, calculated via Homography)
• V: Walking velocity (meters/sec, retrieved from IMU sensor)
• Latency_total: Hardcoded to 40ms (12ms logic processing + 28ms solenoid mechanical spring delay)

5.3 Worked Scenario Execution

1. Camera captures weed at exactly D = 0.45 meters ahead.
2. IMU records walking speed at V = 1.2 m/s.
3. Bare transit time = 0.45 / 1.2 = 0.375s (375ms).
4. Time_to_Impact (Ti) = 375ms - 40ms = 335ms.
5. Result: Software suspends the thread for 335ms, fires the MOSFET for 50ms. Herbicide physically impacts the weed with ±5mm tolerance.

6. Raspberry Pi Firmware Architecture

The code deployed to the Raspberry Pi (`main_rpi.py`) is written in highly concurrent Python to prevent the camera buffer from backing up.

6.1 Threaded Asynchronous Design

  • Thread 1 (VideoCaptureQueue): Pulls frames from the OV5647 CSI port as fast as possible, holding only the newest frame and discarding stale data to prevent latency lag.
  • Thread 2 (InferenceLoop): Evaluates YOLO26 on the current requested frame. Updates the WeedTracker state machine.
  • Thread 3 (GPIO_Actuation): Listens for incoming Ti (Time-to-Impact) payloads. Utilizes standard Rpi.GPIO library to cycle Pin 17 HIGH and LOW without blocking the InferenceLoop.

6.2 Pinout Architecture

BOARD LAYOUT (Raspberry Pi 4 40-pin Header) ----------------------------------------------- GPIO 17 ----> N-Channel MOSFET Gate (IRLZ44N) [Controls 12V Solenoid Valve] GPIO 27 ----> Status LED (System Armed) I2C_SDA ----> IMU Sensor (SDA) I2C_SCL ----> IMU Sensor (SCL) CSI Port ----> OV5647 Ribbon Cable

7. Hardware Deployment Guide

Phase 1: Environment Flashing

On the PC console, extract the verified model weights directly into the required inference format:

PS > python 04_evaluate.py # Audit final crop metrics PS > python 05_export.py # Generates standard best.onnx PS > scp models/best.onnx pi@192.168.1.10:/home/pi/FasalAstra_AI/models/

Phase 2: Wand Construction & Homography Calibration

The physical camera must be mounted exactly at a 45-degree angle facing the ground from the wand chassis.

  1. Run python rpi/field_calibrate.py on the Pi terminal.
  2. Place a physical measuring tape under the wand starting from 0cm to 100cm.
  3. Observe the pixel Y-coordinates generated by the calibration script for marks at 30cm, 50cm, and 70cm.
  4. Input those direct measurements into homography.py's numpy interpolation table.

Phase 3: The MOSFET Solenoid Protection Circuit

Do NOT connect a 12V solenoid valve directly to the Raspberry Pi GPIO pins! You will permanently destroy the CPU.

Use a standard IRLZ44N N-Channel MOSFET. Connect GPIO 17 to the Gate pin (with a 10k pulldown resistor). Connect the 12V battery to the solenoid, grounding it through the Drain and Source of the MOSFET. Include a 1N4007 Flyback Diode across the solenoid coil to absorb voltage spikes during pump shutoff.

10. Limitations & Risks

Risk NodeSeverityEngineering Mitigation
Variable Walking Speeds Medium If the IMU sensor drifts, kinematic calculation Ti becomes misaligned. A Kalman Filter upgrade in the IMU library may be required.
Camera FPS Drop High If Raspberry Pi thermal throttles outdoors in the sun (>85°C), FPS will drop below 10 FPS, causing calculation lag. Requires a physical 5V cooling fan on the Pi.
1D Homography Margin Medium Current math assumes weeds are in the center physical plane. Weeds on the extreme left/right edges of the camera lens will have distorted distance values due to optical lens warp.
