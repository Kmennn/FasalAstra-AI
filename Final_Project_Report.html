1. Executive Summary

FasalAstra_AI is an AI-powered autonomous weed detection and precision herbicide spraying system designed for Indian agriculture. It utilizes YOLOv8-nano for detection and a custom kinematic pipeline on an ESP32-S3 for precise timing.

Current Status: Software pipeline 95% complete. AI model achieves 85.7% mAP50 accuracy.
